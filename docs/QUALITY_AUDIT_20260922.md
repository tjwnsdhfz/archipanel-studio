# 프로젝트 복구와 샘플 표현 개선

## 수정
- 현재 생성되는 schemaVersion 1.4 패키지를 다시 열 수 있도록 복구. 이전 1.0~1.3 마이그레이션 유지.
- 출력 요청 전에 원본 자산이 로컬 저장소에 있는지 확인. 누락 원본을 조용히 생략하지 않고 파일명을 알려주고 중단.
- 소개 화면의 하드코딩된 레이아웃 점수 92/95/89, CONFIDENCE 0.96, 원본 역추적 100%, 잘못된 블록 개수 제거.
- 샘플 작업 흐름은 실제 파일 처리 결과가 아니라는 점을 표시. 계산되는 규칙 기반 크리틱은 유지.

## 검증
잠금 파일 기준 pnpm install --frozen-lockfile, 프런트엔드 32개 테스트, 빌드 통과. Python 28개 통과/8개 건너뜀. 건너뛴 검사는 통과로 간주하지 않는다. 재열기 5개 버전·미지원 버전·누락 자산 출력 차단 회귀 테스트 포함.

## 남은 실사용 검증
대형 실제 PSD/PSB를 Photoshop 렌더와 대조, 실제 패널 패키지 자산·폰트 왕복, 장시간 편집과 브라우저 저장 용량 복구, 출력물의 실제 인쇄 검증. 이 변경은 상용 편집기 수준의 호환성을 주장하지 않는다.


## 의존성 및 브라우저 검증
Fabric 7.4.0, Vite 6.4.3, Vitest 4.1.11로 갱신 후 pnpm audit 0건(2026-09-22). Fabric 7의 원점·마우스 기본값 변경에 대응해 좌상단 원점과 기존 버튼 동작을 명시했다. 업데이트 후 32개 테스트와 빌드 통과. 실제 브라우저에서 사각형 생성·실행 취소·다시 실행 확인. 정적 프리뷰만 실행하여 backend preview/font 요청은 500을 반환했다. 서버 연동 전체 E2E 통과로 해석하지 않는다.
